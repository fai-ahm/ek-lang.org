Ek — grammar-constrained

Ek has no construct for an unchecked write. Every buffer is declared with an explicit bounded size (⟦τ type, σ size⟧) and the grammar has no unbounded copy primitive. When the model is forced to stay within Ek's grammar, the unsafe pattern has no valid surface to land on.

C — unconstrained

C's strcpy and similar functions perform no bounds checking. A fixed-size buffer like char buf[64] can be overwritten past its end if the input is longer. This is the root cause of vulnerabilities like Heartbleed. The model is free to write it because C allows it.

Disclaimer: Ek does not yet have a working compiler or parser. This demo shows that constraining an LLM's output to Ek's grammar changes what unsafe code the model produces — it does not yet show mathematically enforced safety, which requires a real parser and is a future milestone.
